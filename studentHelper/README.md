### Локално стартиране

За локална разработка стартирайте бекенда на порт `5000`, а в `studentHelper/` изпълнете `npx expo start`. По подразбиране приложението използва `http://localhost:5000` за API заявките.

Ако отваряте приложението на физически телефон, задайте `EXPO_PUBLIC_API_URL` на локалния IP адрес на компютъра, например:

```bash
EXPO_PUBLIC_API_URL=http://192.168.1.10:5000 npx expo start
```

Заменете `192.168.1.10` с IP адреса на компютъра в локалната мрежа. Телефонът и компютърът трябва да са свързани към една и съща мрежа.
